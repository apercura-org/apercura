# Code of Conduct

Apercura adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: we want participation in this project to be a harassment-free experience for
everyone. Be respectful, welcome different viewpoints, accept constructive criticism, and focus
on what is best for the community. Harassment, insults, and publishing other people's private
information are not acceptable.

The full text, including the enforcement guidelines, is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## Reporting

To report unacceptable behaviour, contact the project maintainers privately through the
repository's GitHub owner profile. All reports are reviewed promptly and handled
confidentially.
