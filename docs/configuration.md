# Configuration

Every setting is an environment variable, read from a single `.env` file at
the repository root (the web app, the import and the migrations share it) or
from the host's environment. The web app validates its variables at start-up
with the schema in `apps/web/src/env.ts`; `SKIP_ENV_VALIDATION=1` skips that
check (CI lint jobs, Docker image builds).

`bun run keys:generate` prints fresh values for every secret below that is
marked _generate_.

## Web app

| Variable                                                                                | Required       | Role                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------------------------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NODE_ENV`                                                                              | no             | `development`, `test` or `production` (set by Next.js).                                                                                                                                                                                                                                                                                                                                                              |
| `APP_URL`                                                                               | yes            | Public origin, e.g. `https://apercura.health`. Canonical URLs, JSON-LD, sitemaps, emails and the canonical host redirect use it. Set it **at build time too**: static pages bake it.                                                                                                                                                                                                                                 |
| `DATABASE_URL`                                                                          | yes            | PostgreSQL (PostGIS) connection of the app role (`apercura_app`). Without it a build still works (see `docs/public-site.md`).                                                                                                                                                                                                                                                                                        |
| `DATABASE_URL_MIGRATE`                                                                  | no             | Connection used by `bun run db:migrate` when it needs more rights than the app (extensions, roles).                                                                                                                                                                                                                                                                                                                  |
| `DATABASE_POOL_MAX`                                                                     | no             | Size of the app's connection pool (default 10).                                                                                                                                                                                                                                                                                                                                                                      |
| `BETTER_AUTH_SECRET`                                                                    | for auth       | _generate_. Signs sessions and auth tokens.                                                                                                                                                                                                                                                                                                                                                                          |
| `BETTER_AUTH_URL`                                                                       | no             | Origin Better Auth checks requests against; defaults to `APP_URL`.                                                                                                                                                                                                                                                                                                                                                   |
| `PSC_CLIENT_ID`, `PSC_CLIENT_SECRET`, `PSC_ISSUER`                                      | no             | Pro Santé Connect (OpenID Connect) for claiming pages, once enabled.                                                                                                                                                                                                                                                                                                                                                 |
| `ENCRYPTION_KEYS`                                                                       | for booking    | _generate_. Master keys of the application-level encryption, `version:base64key` comma-separated.                                                                                                                                                                                                                                                                                                                    |
| `ENCRYPTION_ACTIVE_KEY`                                                                 | for booking    | Version of `ENCRYPTION_KEYS` used to encrypt new data.                                                                                                                                                                                                                                                                                                                                                               |
| `BLIND_INDEX_KEY`                                                                       | for booking    | _generate_. Key of the blind indexes (searching encrypted emails and phones).                                                                                                                                                                                                                                                                                                                                        |
| `SMTP_URL`, `MAIL_FROM`                                                                 | for auth       | Outgoing mail (`smtp://user:pass@host:port`) and sender address. Mailpit in development.                                                                                                                                                                                                                                                                                                                             |
| `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_PUBLIC_URL` | no             | S3-compatible storage (photos, claim documents), once used.                                                                                                                                                                                                                                                                                                                                                          |
| `JOBS_SECRET`                                                                           | no             | Shared secret of the scheduled job endpoints.                                                                                                                                                                                                                                                                                                                                                                        |
| `REVALIDATE_SECRET`                                                                     | for the import | HMAC secret of `POST /api/revalidate`; the import signs its cache tags with it. Without it the endpoint answers 503.                                                                                                                                                                                                                                                                                                 |
| `TRUSTED_PROXY_COUNT`                                                                   | behind a proxy | Number of reverse proxies in front of the app. It decides which `X-Forwarded-For` entry is the client and whether `X-Forwarded-Host` is read. Default 0: forwarded headers are ignored, so every visitor shares one rate-limit bucket.                                                                                                                                                                               |
| `RATE_LIMIT_KEY`                                                                        | recommended    | _generate_. Secret HMAC-SHA256 key that turns client IP addresses into rate-limit keys, so `directory.rate_limits` never stores a raw IP. Any random string of 32 bytes or more (base64 of 32 random bytes: `bun run keys:generate` or `openssl rand -base64 32`). Unset: each process draws a random key at start (counters reset on restart and are split across instances). Rotating it only resets the counters. |
| `CANONICAL_HOST_REDIRECT`                                                               | no             | `false` disables the production 308 from any other host to `APP_URL`.                                                                                                                                                                                                                                                                                                                                                |
| `PUBLIC_HDS_HOST`                                                                       | no             | Name of the HDS-certified host that runs production. Set it only where health data really is hosted there: the public pages then say so.                                                                                                                                                                                                                                                                             |
| `FEATURE_BOOKING`                                                                       | no             | `true` enables online booking (not yet available). Default `false`: directory only, no health data.                                                                                                                                                                                                                                                                                                                  |
| `NEXT_PUBLIC_MAP_STYLE_URL`                                                             | no             | MapLibre style URL (default OpenFreeMap positron). Inlined at build time.                                                                                                                                                                                                                                                                                                                                            |
| `PORT`                                                                                  | no             | Port of `next start`.                                                                                                                                                                                                                                                                                                                                                                                                |

## Open data import (`packages/etl`)

| Variable                                                                                         | Role                                                                           |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| `DATABASE_URL_ETL`                                                                               | Connection of the `apercura_etl` role (falls back to `DATABASE_URL`).          |
| `ETL_PROFESSIONS`                                                                                | Profession codes to import (default `10,40,50`).                               |
| `ETL_WORK_DIR`                                                                                   | Temporary directory for downloads (about 1.2 GB).                              |
| `ETL_SOURCE_DIR`                                                                                 | Read the source files from a directory instead of downloading them (fixtures). |
| `ETL_ANS_URLS`, `ETL_AMELI_URL`, `ETL_FINESS_DATASET_URL`, `ETL_GEO_API_URL`, `ETL_GEOCODER_URL` | Override the source URLs (see `docs/data-import.md`).                          |
| `APP_URL`, `REVALIDATE_SECRET`                                                                   | Where and how the import sends its cache tags after a run.                     |

## Tests and tooling

| Variable                | Role                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------- |
| `SKIP_ENV_VALIDATION`   | `1` skips the start-up validation of the web app's variables.                         |
| `DATABASE_URL_TEST`     | Database of the web access-control integration tests (skipped when unset).            |
| `ETL_TEST_DATABASE_URL` | Throwaway database of the import integration test (destructive; skipped when unset).  |
| `E2E_PORT`              | Port of the Playwright production server (default 3100; development on the next one). |
| `MAILPIT_URL`           | Mailpit API read by the sign-up end-to-end test.                                      |
| `CI`                    | Set by CI: retries, no server reuse, GitHub reporter.                                 |
