Chez le dentiste, il faut distinguer deux types de soins. Les soins courants (consultation, carie, détartrage) sont remboursés à 60 % du tarif de la convention. Pour les prothèses, comme les couronnes, un devis est obligatoire. Le 100 % Santé permet d’en avoir sans reste à payer, chez un dentiste conventionné et si votre complémentaire santé est un contrat responsable.

## Quels soins sont remboursés, et à quel taux ?

L’Assurance Maladie rembourse **60 %** du tarif de la convention pour :

- les consultations ;
- les soins conservateurs, c’est-à-dire les soins qui gardent la dent : détartrage, traitement d’une carie, dévitalisation ;
- les soins chirurgicaux, comme l’extraction d’une dent.

Le taux est différent dans deux cas :

- **90 %** si vous relevez du régime local d’Alsace-Moselle ;
- **100 %** si les soins sont liés à une affection de longue durée (ALD).

Chez le dentiste, la participation forfaitaire de 2 € « ne s’applique pas ». Vous n’avez pas non plus besoin de passer par votre médecin traitant pour être remboursé, sauf pour certains actes chirurgicaux lourds.

Pour les montants exacts, consultez la page de l’Assurance Maladie sur les [tarifs et remboursements des consultations et soins dentaires](https://www.ameli.fr/assure/remboursements/rembourse/soins-protheses-dentaires-optique-audition/consultations-soins-protheses-dentaires/consultations-soins-dentaires).

### Le dentiste peut-il dépasser les tarifs ?

Pour les soins courants, un dentiste conventionné applique en principe le tarif de la convention. Un dépassement est possible dans trois cas :

- vous faites une demande particulière (on parle d’« exigence particulière », notée DE) ;
- le dentiste a un droit permanent à dépassement (noté DP) ;
- vous consultez un stomatologue de secteur 2.

Dans tous les cas, le dépassement doit rester fixé « avec tact et mesure ». Le dentiste doit vous en informer avant.

## Prothèses : les trois paniers du 100 % Santé

Pour les prothèses (couronnes, bridges, dentiers), l’Assurance Maladie classe les soins en trois groupes, appelés « paniers » :

- **le panier 100 % Santé** : le prix est plafonné et vous n’avez rien à payer, à deux conditions : le dentiste est conventionné et votre complémentaire santé est un contrat responsable ;
- **le panier aux tarifs maîtrisés** : le prix est plafonné, mais un reste à payer modéré est possible ;
- **le panier aux tarifs libres** : le prix est libre, et le reste à payer peut être plus important, selon votre contrat.

Le contrat responsable est un type de contrat de complémentaire santé encadré par la loi. Selon l’Assurance Maladie, ce type de contrat représente « 95 % des contrats vendus sur le marché ». Pour savoir si c’est le cas du vôtre, demandez à votre mutuelle.

> **À retenir.** « L’offre 100 % Santé dentaire est disponible auprès de tous les dentistes. » Quand une solution 100 % Santé existe, le devis doit la mentionner.

Voici quelques prix maximum du panier 100 % Santé, au 1er janvier 2026, selon l’Assurance Maladie :

- couronne céramo-métallique sur une incisive, une canine ou une première prémolaire : prix maximum 515 €, base de remboursement 120 € ;
- couronne en zircone sur une dent autre qu’une molaire : prix maximum 453,20 €, base de remboursement 120 € ;
- couronne en alliage non précieux : prix maximum 298,70 €, base de remboursement 120 €.

Ces prix peuvent changer. La liste complète est sur la page de l’Assurance Maladie sur les [prothèses dentaires et le 100 % Santé](https://www.ameli.fr/assure/remboursements/rembourse/soins-protheses-dentaires-optique-audition/consultations-soins-protheses-dentaires/protheses-dentaires).

## Que doit contenir le devis du dentiste ?

Le dentiste doit vous remettre un **devis** avant tout traitement « à entente directe », c’est-à-dire dont il fixe lui-même le prix. C’est le cas aussi si vous avez la Complémentaire santé solidaire. Le devis est obligatoire pour l’orthodontie et pour les couronnes, les bridges et les dentiers.

Pour chaque prothèse proposée, le devis indique :

- le panier auquel elle appartient ;
- le montant remboursé par l’Assurance Maladie ;
- le lieu de fabrication de la prothèse, dans l’Union européenne ou en dehors ;
- une partie « information alternative thérapeutique ».

Cette dernière partie présente une autre solution. Ce doit être une solution du panier 100 % Santé. Si ce n’est pas possible techniquement, ce doit être une solution du panier aux tarifs maîtrisés.

Quelques règles à connaître :

- vous signez le devis seulement si vous l’acceptez ;
- le devis n’a pas de date limite, sauf si le dentiste en a indiqué une ;
- le dentiste peut vous orienter vers un confrère pour l’option 100 % Santé, mais il doit vous le dire ;
- quand il pose la prothèse, il vous remet un « certificat de conformité ».

## M’T dents : des rendez-vous de prévention offerts

Avec **M’T dents**, l’Assurance Maladie offre un rendez-vous de prévention chez le dentiste chaque année, « dès l’âge de 3 ans et jusqu’à leurs 24 ans ».

- Si des soins sont nécessaires, ils sont aussi gratuits s’ils sont faits « dans les 6 mois suivants votre rendez-vous ».
- Ne sont pas compris : l’orthodontie, les prothèses et les techniques de réparation inlay-onlay. Si le dentiste vous les propose, il doit vous informer de leurs tarifs et de leurs remboursements.
- Les bénéficiaires de l’aide médicale de l’État (AME) n’y ont pas accès.
- Apportez la carte Vitale (celle du jeune s’il en a une, ou celle d’un parent) et la carte ou l’attestation de mutuelle. Sans mutuelle, l’Assurance Maladie prend tout en charge.

### Pendant la grossesse

Si vous êtes enceinte, un examen de prévention bucco-dentaire est aussi pris en charge en totalité par l’Assurance Maladie. Il est possible à partir du 4e mois de grossesse et jusqu’au 6e mois après l’accouchement. Pour le reste du suivi, lisez le guide [Suivre sa grossesse avec une sage-femme](/fr/guides/suivi-de-grossesse-sage-femme).

## Comment trouver un dentiste et vérifier son conventionnement ?

L’annuaire santé de l’Assurance Maladie indique le secteur de conventionnement de chaque professionnel, son option tarifaire, s’il accepte la carte Vitale et s’il accepte l’appli carte Vitale. Il ne montre plus les tarifs. Pour connaître un prix, demandez un devis.

Sur Apercura, la page d’un dentiste indique s’il est conventionné et s’il accepte la carte Vitale, d’après l’annuaire de l’Assurance Maladie, quand elle a pu y être rapprochée avec certitude. Elle n’indique pas s’il accepte l’appli carte Vitale.

## Ce que vous pouvez faire maintenant

- Cherchez un dentiste près de chez vous dans l’[annuaire des chirurgiens-dentistes](/fr/chirurgien-dentiste).
- Avant une prothèse, demandez le devis et l’option 100 % Santé. Vérifiez avec votre mutuelle ce qu’elle rembourse.
- Pour un enfant ou un jeune de 3 à 24 ans, prenez rendez-vous pour l’examen M’T dents de l’année.
- Pour la carte Vitale et le tiers payant, lisez le guide [Carte Vitale et appli carte Vitale : l’essentiel](/fr/guides/carte-vitale-et-appli-carte-vitale).
